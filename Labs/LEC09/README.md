# 소닉 애니메이션 뷰어

`sonic_animation_viewer.py`는 Python 3와 pico2d를 사용하는 단일 파일 뷰어입니다. `sonic-sprite.png`를 실행 파일과 같은 폴더에 두세요. 이미지 경로는 실행 파일 기준이므로 터미널의 현재 위치와 관계없이 실행됩니다.

## 실행

이 저장소에는 검증용 Python 환경 `.venv`를 준비했습니다. `Labs/LEC09` 폴더의 PowerShell에서 실행합니다.

```powershell
& ..\..\.venv\Scripts\python.exe .\sonic_animation_viewer.py
```

VS Code에서는 **Python: Select Interpreter**로 저장소의 `.venv/Scripts/python.exe`를 선택한 뒤 실행 파일을 열고 **Run Python File**을 누르세요. 현재 시스템의 `python` 명령은 Microsoft Store 실행 별칭이므로, 준비된 환경의 Python을 선택해야 합니다.

다른 Python 3 환경에서는 `python -m pip install pico2d`로 라이브러리를 설치한 뒤 `python sonic_animation_viewer.py`로 실행할 수 있습니다. 실행 자체에는 Pillow가 필요하지 않습니다. `.venv`는 로컬 환경이며 Git에는 포함하지 않습니다.

## 동작

기본 실행은 처음 약 7.5초 동안 대기·표정 등의 제자리 동작을 재생하고, 그다음 걷기부터 이동합니다. 창 제목에서 현재 동작명과 이동·제자리·대기 상태 및 반복 횟수를 확인할 수 있습니다. 코드 수정 후에는 기존 창을 닫고 다시 실행해야 합니다.

걷기부터 바로 확인하려면 `Labs/LEC09`에서 다음 명령을 사용합니다.

```powershell
& ..\..\.venv\Scripts\python.exe .\sonic_animation_viewer.py --start-animation 걷기
```

`--start-animation 달리기`처럼 다른 동작도 선택할 수 있습니다. 시작 순서만 바뀌며 전체 15동작을 모두 순환합니다.

- 이미지 본문의 **15동작·76프레임**을 순서대로 재생합니다.
- 각 동작을 **5회** 재생하고 마지막 프레임을 **0.5초** 유지합니다.
- 마지막 동작까지 재생하면 첫 동작으로 돌아가 무한 반복합니다.
- **1200×800** 창에서 모든 프레임을 공통 약 **10.67배**로 확대합니다. 최대 프레임 높이는 **480픽셀**이며, 프레임별 몸통 기준점과 행별 바닥 기준선을 사용합니다.
- 걷기·가속·몸 회전·공 회전·달리기·빠른 달리기는 화면 안에서 **왕복 이동**합니다. 진행 방향에 맞춰 이미지를 좌우 반전하며, 팔다리와 효과를 포함해 가장자리에서 최소 48픽셀의 여백을 유지합니다.
- 짙은 남색 무대에 원근 바닥·그림자·속도선과 최대 5개의 짧은 잔상을 표시합니다. 이동 동작의 프레임 속도도 높여 빠르고 역동적으로 표현합니다. 대기와 동작 전환 시 잔상을 제거합니다.
- 같은 동작의 5회 반복 중에는 이동을 이어가고, 0.5초 대기 중에는 마지막 위치와 방향을 유지합니다. 다음 동작은 기본 중앙 기준점에서 오른쪽을 향해 시작합니다.
- 창 닫기 또는 **Esc**로 종료합니다. 대기 중에도 종료 입력에 응답합니다.
- 긴 시스템 지연이 발생하면 한 프레임만 진행하여 화면에 보이지 않은 동작을 연속으로 건너뛰지 않습니다.

동작별 프레임 수는 순서대로 `7, 2, 1, 1, 12, 6, 8, 7, 6, 6, 6, 2, 8, 2, 2`입니다. 이름과 순서는 실행 파일 상단의 이미지 조사 주석에서 확인할 수 있습니다. 명칭은 그림의 포즈에 따라 붙였으며, 1프레임 독립 포즈도 포함합니다. 제목·제작자 문구·크레딧 옆 노란색/갈색 장식 캐릭터는 제외했습니다. 원본 이미지는 수정하지 않았습니다.

| 이동 동작 | 속도 (화면 픽셀/초) | FPS |
| --- | --- | --- |
| 걷기 | 180 | 12 |
| 가속 | 340 | 16 |
| 몸 회전 | 300 | 16 |
| 공 회전 | 420 | 18 |
| 달리기 | 460 | 16 |
| 빠른 달리기 | 680 | 20 |

나머지 동작은 제자리에서 재생합니다. 긴 창 이동이나 시스템 지연이 있을 때 이동량도 프레임 재생과 함께 제한하여 순간이동을 피합니다.

## 검증 명령

창을 열지 않는 내부 검증:

```powershell
& ..\..\.venv\Scripts\python.exe .\sonic_animation_viewer.py --self-test
```

전체 순서를 두 번 재생한 뒤 자동 종료하는 검증:

```powershell
& ..\..\.venv\Scripts\python.exe .\sonic_animation_viewer.py --cycles 2
```

`--cycles`를 생략하면 무한 반복합니다. 내부 검증 17개는 프레임 좌표와 범위, 전체 목록, 5회 완료 경계, 0.5초 대기, 1프레임 동작, 서로 다른 프레임 수와 속도, 두 번의 순환, 긴 시간 지연, 확대 후 화면 범위 및 종료 입력에 더해 이동 속도, 경계 반전, 양쪽 방향의 화면 범위, 대기 중 정지, 동작 전환 시 위치 초기화, 좌우 반전 그리기, 시작 동작 선택, 창 제목의 상태 표시 및 잔상의 수명·개수 제한·대기 중 제거를 확인합니다.
