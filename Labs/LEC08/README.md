# DRILL #8 애니메이션 뷰어

실행 파일: `animation_viewer.py` (Python 3 + pico2d)

VS Code에서 이 파일을 열고 **Run Python File**로 실행합니다.
이미지는 소스 파일 위치를 기준으로 불러오므로 터미널의 현재 폴더와 무관합니다.
기본 실행은 무한 반복이며, Esc 또는 창 닫기 버튼으로 종료합니다.

## 구현 조건

- 사용자 제공 Gemini 생성 사무라이 스프라이트를 `samurai_animations.png`로 포함했습니다.
- 대기(Idle), 걷기(Walk), 달리기(Run), 점프(Jump), 공격(Attack), 방어(Block)의 6개 동작을 순서대로 재생합니다. 동작 명칭은 이미지 포즈에 따른 분류입니다.
- 각 동작의 모든 프레임을 5회 반복한 뒤, 마지막 프레임에서 추가로 1초 정지합니다.
- 마지막 동작 이후 첫 동작으로 돌아가 무한 반복합니다.
- 800×600 창 중앙 부근에 몸통 기준점을 고정하고, 원본을 1.85배로 확대합니다. 가장 작은 프레임 높이도 344픽셀이므로 화면 높이의 절반보다 큽니다.
- 정지 중에도 이벤트를 처리하므로 창 이동·닫기·Esc 입력에 응답합니다.

## 가산점 구현 설명 (제출 시 함께 기재)

1. **프레임별 크기가 다른 잘라내기 영역 지원**: 고정된 격자 크기로 나누지 않고 각 프레임의 `(left, top, width, height)`를 따로 기록했습니다. 칼과 공격 효과를 포함하는 영역이 서로 다릅니다. 별도 몸통 기준점으로 크기가 바뀌어도 캐릭터 위치가 흔들리지 않도록 보정합니다.
2. **애니메이션별 서로 다른 프레임 개수 지원**: 각 동작은 순서대로 **5, 7, 8, 8, 10, 6프레임**이며, 각 목록의 길이에 맞춰 재생하고 반복 횟수를 계산합니다.

## 이미지 관련 한계

제공된 이미지에는 체크무늬가 실제 픽셀로 들어 있으므로 실행 화면에도 보입니다. 원본 이미지를 수정하거나 투명 배경으로 바꾸지 않았습니다. 일부 대기·걷기 프레임은 포즈 변화가 작고, 동작의 자연스러움은 제공된 그림의 영향을 받습니다.

## 검증

이 폴더에서 `python -m unittest -v`로 반복 횟수, 정지 시간, 순환, 이미지 범위, 확대 후 화면 범위를 확인할 수 있습니다.
`python animation_viewer.py --cycles 2`는 전체 순서를 두 번 재생한 뒤 종료하는 검증용 실행입니다. 옵션을 생략하면 무한 반복합니다.

개발은 `DRILL08 01`부터 기능을 추가하며 실제 Git 커밋을 남겼습니다. 실행 코드 25단계, 자동 검증 및 설명 추가를 포함해 총 27개 커밋입니다. 커밋 개수만으로 최종 채점 결과를 보장하지는 않습니다.
